### 3. enrich-v2 프롬프트 개선
- **문제**: "문서 내 빈 섹션" 기반 질문 생성 → 섹션 자체가 없는 누락은 감지 못함
- **해결**: 3단계 분석 구조 추가
  1. 업무 유형 추론 (매장 판매직 / 사무직 / 현장직 등)
  2. 직종 필수 체크리스트 내부 생성 → 문서와 비교
  3. 기존 빈 섹션 / inferred / 절차 비약 감지
- 질문 수: 3~5개 → 5~7개로 확대
- **결과**: 거스름돈 처리 + 안경 보관 위치 질문 자동 생성 확인

### 4. ffmpeg ENOENT 버그 수정
- 에러: `spawn #ROOT\node_modules\ffmpeg-static\ffmpeg.exe ENOENT`
- 원인: Next.js webpack이 ffmpeg-static 바이너리 경로를 `#ROOT` 플레이스홀더로 치환
- 해결: `next.config.ts`에 `serverExternalPackages: ["ffmpeg-static"]` 추가
- 확인: 33MB 영상 → ffmpeg mp3 추출 성공 → STT 단계 진입

### 5. STT 파이프라인 확인
