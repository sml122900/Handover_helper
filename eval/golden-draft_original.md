# 골든셋 초안 (40문항)

- 상태: 초안 — 설계 채팅 작성, **사용자 검토·수정 후 확정**
- 확정 후 Claude Code가 `eval/golden.jsonl`로 변환한다. 확정 전에는 검색 코드를 작성하지 않는다.
- 질문은 사실표와 다른 **신입 구어체**로 썼다. 사용자는 최소 10문항을 본인 말투로 고치고 `수정` 열에 표시한다.
- `혼동 주의`: 매장 필터 없이 검색하면 섞이기 쉬운 다른 매장의 사실. 실험 B에서 "매장 혼동 오답"을 셀 때 쓴다.
