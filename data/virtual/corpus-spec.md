# 가상 코퍼스 사양 (corpus-spec)

- 상태: **승인됨 (2026-09-30, 이성민)**
- 모든 매장·인물은 **가상**이다. 실제 상호·주소·전화번호·비밀번호를 쓰지 않는다.
- 이 사양은 트랜스크립트 생성(D0)과 골든셋 정답의 **유일한 기준**이다. 사실 ID는 바꾸지 않는다.

## 트랜스크립트 생성 규칙 (D0에서 Claude Code가 따를 것)
1. 매장별로 전임자가 신입에게 말로 알려주는 **인수인계 영상 트랜스크립트**를 쓴다. 분량 8~15분, `[mm:ss]` 타임스탬프 포함.
2. **사실표의 모든 사실을 반드시 포함**하되, 사실표 문장을 그대로 쓰지 말고 **구어체로 풀어서** 말한다. 예: "라스트오더 21:30" → "아홉 시 반에 마지막 주문 받아요".
3. 순서는 실제 설명처럼 섞는다(사실표 순서대로 읽지 않는다). 군말("어… 그리고", "아 맞다")과 한두 번의 말 바꿈을 넣는다.
4. **의도적 공백 항목은 절대 언급하지 않는다.** "그건 나중에 알려줄게요" 같은 암시도 금지(파이프라인 채점에서 겪은 문제 재발 방지).
5. 사실표에 없는 새 규칙·수치를 추가하지 않는다. 분위기용 잡담은 허용하되 업무 규칙이 되면 안 된다.
6. 완성 후 기존 `npm run convert`로 문서화하고, 각 사실 ID가 문서·트랜스크립트 어디에 있는지 `eval/fact-spans.json`에 매핑한다. 누락된 사실이 있으면 트랜스크립트를 고쳐 다시 변환한다.
