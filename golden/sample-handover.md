# 정답 문서: 주간 뉴스레터 발송 업무 (마케팅팀 김민수 → 후임자)

## 업무 개요
- 매주 목요일 오전 뉴스레터 발송. 회사 공식 채널로 중요도 높음.

## 업무 절차
1. 매주 월요일 콘텐츠팀 박지영 매니저에게 슬랙으로 이번 주 소재 리스트 요청·수령
2. 소재 중 3개 선택 → 이메일 툴 '스티비'의 '위클리 베이직' 템플릿에 입력
3. 수요일까지 초안 작성 → 최성훈 팀장에게 검토 요청 (피드백은 보통 수요일 오후)
4. 피드백 반영 → 목요일 오전 10시 발송 예약 (대상: 전체 구독자 리스트, 약 1.2만 명 — 정확한 수는 스티비 대시보드 확인)

## 계정·접근 권한
- 스티비 계정: marketing@company.com (비밀번호는 영상에 노출됨 → 보안팀에 요청해 변경 필요)

## 관계자 맵
- 박지영 (콘텐츠팀 매니저): 매주 소재 리스트 제공, 전임자 퇴사 후 백업 문의처
- 최성훈 (팀장): 수요일 초안 검토·피드백

## 일정·데드라인
- 월요일: 소재 수령 / 수요일: 초안·검토 / 목요일 오전 10시: 발송
- 매월 마지막 주: 월간 리포트 병행 발송 → 업무량 2배, 미리 준비

## 주의사항·암묵지
- 발송 전 반드시 본인 메일로 테스트 발송 (과거 이미지 깨짐 사고)
- 광고성 문구 포함 시 제목에 (광고) 표시 필수 (법적 의무)

## 미해결 이슈
- 구독 해지율 상승 원인 분석 중단 상태. 데이터는 노션 페이지에 정리돼 있음.

## FAQ
- Q. 구독자가 메일을 못 받았다고 하면? → 스팸함 확인 안내, 없으면 스티비 발송 로그 확인
