# 정답: 보드다 알바 마감조 인수인계

> 작성 기준: 메인 영상 + 보완 영상 2개 (총 3개 영상) 전체 반영
> 불명확한 부분은 ⚠️ 표시 — AI가 이 부분을 어떻게 처리하는지 채점 포인트

---

## 1. 업무 개요
- 코엑스 팝업 매장 알바 마감조 업무
- 주요 업무: 안경·선글라스 판매, 고객 응대, 매장 청결 및 마감 관리
- 중요도: high

---

## 2. 절차

### 출근 시
1. 업무용 핸드폰 비밀번호 **8351** 입력
2. 카카오톡 → **팝업오프라인** 채널에 "출근했습니다" 카톡 전송
3. 서랍장 제일 아래 칸에서 **허리띠** 꺼내 착용
4. **안경** 착용 (브랜드 이미지 유지 목적)
5. 업무 시작

### 판매 (포스기 결제)
1. 포스기 비밀번호 **0000** 입력
2. **상품 등록** 버튼 누르기
3. **보다** 버튼 누르기
4. 판매 단가 입력: **8만 9천 원** 또는 **10만 9천 원** 중 선택
5. **엔터** 누르기
6. 결제 방법 선택: **신용카드** 또는 **현금** 버튼
7. 포인트 적립 여부 고객에게 확인
8. 카드 단말기에 카드 삽입 또는 태그 (외국인은 태그 많이 함)
9. **영수증 반드시 출력**해서 고객에게 전달

### 일련번호로 상품 찾기
1. 안경 안쪽 한 면에 브랜드 번호, 반대 면에 일련번호 표시
2. 일련번호 형식: 숫자 4~5자리 + 색상 코드 (예: 5733CO, 58005)
   - 숫자 부분 = 모델 번호
   - 뒤의 문자 = 색상 코드
3. 케이스 바코드: **00 + 모델번호 + 색상번호** 형식으로 구성
   - 예: 5733, 색상 5번 → 바코드에 **005733 05** 형태로 표기
4. 케이스는 **내림차순 정렬**이므로 번호 순서대로 찾기
⚠️ 일련번호 읽는 법 설명이 복잡하고 예시가 뒤섞임 — AI가 이를 얼마나 정확히 정리하는지 확인 필요

### 안경·거울 관리
1. 안경 닦기로 진열 안경 주기적으로 닦기 (손상 주의)
2. 거울 먼지 수시로 닦기
3. 에어 블로워로 먼지 제거 (시간 날 때 또는 마감 시)

### 포장
1. 쌓여 있는 박스에서 파우치 꺼내기
2. 파우치에 안경 넣기
3. 영수증 반드시 동봉
4. 종이백에 박스 담아서 고객에게 전달

### 퇴근 시 (마감)
1. 매장 쓰레기통 쓰레기를 화장실 **일반 쓰레기통**에 버리기
2. 비닐봉지는 재활용 — 원래 꽂혀 있던 자리에 다시 꽂기
3. 페넌트(할인 축제 배너) 제자리에 걸기
4. 마감 상태 전체 확인
5. **명찰을 좌석 옆면에 붙여놓고 덮어두기** (집에 가져가면 안 됨)
6. 퇴근

## 3. 장비·위치·물품

| 장비/물품 | 위치 | 용도 | 비고 |
|---|---|---|---|
| 업무용 핸드폰 | 매장 내 | 출근 보고, 카카오톡 | 비밀번호 8351 |
| 포스기 | 계산대 | 결제 처리 | 비밀번호 0000 |
| 허리띠 | 서랍장 제일 아래 칸 | 근무 복장 | 출근 시 착용 |
| 안경 (근무용) | ⚠️ 위치 불명확 | 브랜드 이미지 유지 | 출근 시 착용 |
| 블루투스 스피커 | 매장 내 | 매장 음악 재생 | - |
| 에어 블로워 | 매장 내 | 먼지 제거 | C타입 충전기 전용 |
| 안경 닦기 | 매장 내 | 진열 안경·거울 청소 | - |
| 파우치·박스·종이백 | 매장 내 쌓여 있음 | 판매 상품 포장 | - |
| 명찰 | 퇴근 시 좌석 옆면에 보관 | 근무 중 착용 | 집에 가져가면 안 됨 |
| 쓰레기통 | 매장 내 + 화장실 | 마감 시 쓰레기 처리 | 화장실 일반 쓰레기통으로 버림 |

---

## 4. 일정·루틴

- **출근 시**: 카톡 출근 보고 → 허리띠·안경 착용 → 업무 시작
- **수시**: 매장 순회, 안경·거울 닦기, 고객 응대, 매장 분위기 조성
- **시간 날 때**: 에어 블로워로 먼지 제거
- **퇴근 시**: 쓰레기 처리 → 페넌트 정리 → 명찰 보관 → 마감 확인 → 퇴근

---

## 5. 연락·보고

- **출근 보고**: 카카오톡 **팝업오프라인** 채널에 "출근했습니다" 전송
- ⚠️ 문제 발생 시 연락처 언급 없음 — AI 보강 질문이 이를 짚어야 할 포인트

---

## 6. 예외·꿀팁

- **외국인 고객**: 카드 태그 방식 선호 → 단말기에 태그 또는 삽입 결제
- **호텔 고객**: 코엑스 팝업 한정 40% 할인 적용 가격(8만9천/10만9천)임을 안내
- **포인트 적립**: 모든 결제 전 고객에게 반드시 확인
- **영수증**: 모든 결제 후 반드시 출력해서 전달
- **매장 분위기**: 심심하지 않게 블루투스 스피커로 음악 틀고 수시로 순회
- **에어 블로워 충전**: 반드시 꼬임 있는 C타입 충전기만 사용 (전압 달라서 다른 충전기 사용 시 기기 손상)

---

## 7. 주의사항

- 에어 블로워는 **꼬임 있는 C타입 충전기만** 사용 — 전압이 달라 다른 충전기 연결 시 기기 망가짐
- 안경 닦을 때 **손상 주의**
- 명찰은 **반드시 매장에 두고 퇴근** (좌석 옆면에 보관)
- 비닐봉지는 **재활용** — 버리지 말고 원래 자리에 꽂아두기
- ⚠️ 현금 결제 시 거스름돈 처리 방법 언급 없음

---

## 8. 미해결·인계 항목

- ⚠️ 문제 발생 시 연락할 담당자·연락처 없음
- ⚠️ 현금 결제 시 거스름돈 처리 방법 불명확
- ⚠️ 근무 중 착용하는 안경 위치 불명확
- ⚠️ 매장 오픈 절차 없음 (마감조 영상이라 해당 없을 수 있음)
- ⚠️ 재고 관리·부족 시 처리 방법 없음
